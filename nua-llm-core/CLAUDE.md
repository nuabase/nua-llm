# Instructions

* **The main entry point (`src/index.ts`) must work in both Node.js and edge runtimes (such as Cloudflare Workers or Vercel Edge)**, which lack most Node built-ins. It is also bundled into the main entry point of `nuabase` (nua-client), which has the same rule. So nothing it imports may import `node:` built-in modules (e.g. `node:crypto`, `node:fs`, `node:path`). Use web-standard globals instead (e.g. `crypto.randomUUID()` instead of `import { randomUUID } from "node:crypto"`). The one exception is the Node-only `local-agent` entry point (`src/local-agent.ts`, imported as `nua-llm-core/local-agent`), which runs coding-agent CLIs; only modules reachable from it alone may import `node:` modules. `src/__tests__/entry-points.test.ts` enforces this.
* **nua-llm-core has no build of its own.** Its `exports` point at its TypeScript source, which nua-client type-checks, tests and bundles directly, so a change here is in nua-client's next run without rebuilding anything.
* **Change the in-prompt prompt text only on purpose** (`src/modules/cast/prompts/`). `src/__tests__/cast-prompts.test.ts` pins it. The native-enforcement text may change.
