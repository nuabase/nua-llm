# Instructions

* **The main entry point (`src/index.ts`) must work in both browser and node.js**. It is also bundled into other packages that must work in both browser and node.js. So nothing it imports may import `node:` built-in modules (e.g. `node:crypto`, `node:fs`, `node:path`). Use web-standard globals instead (e.g. `crypto.randomUUID()` instead of `import { randomUUID } from "node:crypto"`). The one exception is the Node-only `local-agent` entry point (`src/local-agent.ts`, imported as `nua-llm-core/local-agent`), which runs coding-agent CLIs; only modules reachable from it alone may import `node:` modules. `src/__tests__/entry-points.test.ts` enforces this.
* **After any changes to nua-llm-core, rebuild both packages** (`pnpm build` in nua-llm-core, then `pnpm build` in nua-client). nua-client's rollup bundles nua-llm-core from its compiled `dist/` folder, not the TypeScript source. A stale dist will silently bundle old code.
* **Keep the in-prompt prompt text unchanged** (`src/modules/cast/prompts/`). The API server stores the prompts it sends, and `src/__tests__/cast-prompts.test.ts` pins the text. The native-enforcement text may change.
